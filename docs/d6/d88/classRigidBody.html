Set the parameters for the rigid body to establish a physical object in the scene.

Parameters
widthWidth of the rigid body in pixels, should be the same as the GameObject sprite.
heightHeight of the rigid body in pixels, should be the same as the GameObject sprite.
xPosHorizontal position of the RigidBody with respect to the center of the object.
yPosVertical position of the RigidBody with respect to the center of the object.
massMass of the RigidBody to be used for physical simulations.
gravityVertical gravity that the RigidBody should be subjected to.
rotationWhether or not the RigidBody is allowed to rotate in 2D space.
