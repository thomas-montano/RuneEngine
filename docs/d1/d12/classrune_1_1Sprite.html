rune::Sprite::Sprite ( std::string  spriteLocation,
unsigned int  drawMode = LINEAR_FILTER

Default constructor for generating a sprite from a PNG file, uses default shader. Use NEAREST_FILTER for pixel art sprites. LINEAR_FILTER is used by default.

Parameters
dimensionsA rune::Vec2 specifying the size of the sprite.
positionA rune::Vec2 specifying the location of the sprite with respect to the bottom left corner.
spriteLocationA filepath for the sprite .png file to be drawn.
