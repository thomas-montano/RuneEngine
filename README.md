# PrivateEye
This is the GitHub for developing the engine being used by the game Private Eye. The game and engine are being developed by Thomas Montano, a Senior at Missouri University of Science and Technology.

## Install
- Download Library
- Run make file

## Engine Features
- Custom 2D renderer
- Customizable Game Objects
- Particle System
- Lighting System
- Physically Accurate Collisions
- Animated Sprites

## System
- Rendering with Cross Platform OpenGL
- Custom Physics Engine
- Debug Interface with imgui
